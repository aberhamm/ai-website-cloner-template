# Interactions

Client controller for class, offer, booking and policy dialogs, the mobile navigation sheet, sticky header state, photo tilt and reveal effects.

Dialogs: centered 512px width, maximum viewport minus32px, padding36px desktop/24px mobile, 8px radius, black50% backdrop. Native dialog focus management and Escape dismissal. Source class descriptions are verbatim; placeholder booking instructions are replaced by concise studio contact text.

Mobile menu: right aligned75vw sheet, max400px, top padding72px, horizontal padding24px. Six section links. Close at top7px/right12px. Desktop header52px, mobile56px. At scrollY20 header becomes white30% with24px blur.

Reduced motion disables reveal/tilt animation. Classes and anchor links remain usable without animation.
